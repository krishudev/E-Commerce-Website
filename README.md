# BrewHaven Roasters - Indian Café Website

A beautiful, fully functional single-page Indian café e-commerce website built with **pure HTML, CSS, and Vanilla JavaScript** (no frameworks, no backend).

Features every real café menu item that Indians love:
- Classic Filter Kaapi & Meter Coffee
- Cappuccino, Cold Brew, Frappés
- Masala Chai, Cutting Chai, Adrak Chai
- Paneer Tikka Sandwich, Cheese Chilli Toast, Cheesecake & more!

### Features
- 100% responsive (looks perfect on mobile & desktop)
- Indian Rupee pricing with 18% GST
- Free shipping above ₹999
- Fully working cart, wishlist, checkout
- All orders saved in browser (LocalStorage)
- Admin panel: View all orders at `?admin=true`
- Live search & category filters
- Beautiful Indian café aesthetic

### Tech Stack
- HTML5
- CSS3 (Flexbox + Grid)
- Vanilla JavaScript (ES6+)
- LocalStorage for cart & orders persistence
